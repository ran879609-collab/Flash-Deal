# CyclePro Pro — 活动产品周期分析与智能提报管理系统

## 一、系统简介

CyclePro Pro 是专为电商运营与供应链精细化管理打造的企业级 Web 管理系统。在原有 CyclePro 业务基准之上进行了系统性工程重构与专业化升级，支持 50,000+ 条超大规模 SKU 与活动记录秒级分析、智能连续提报研判、虚拟化表格渲染、多租户云端持久化存储与 RBAC 权限控制。

---

## 二、核心架构与技术栈

- **前端技术**：React 19 + TypeScript + Tailwind CSS
- **后端架构**：Node.js Express Full-Stack Server (`server.ts`)，挂载 Vite 中间件（Dev）与静态资源托管（Prod）
- **数据存储层**：
  - 默认：本地 WAL（Write-Ahead Logging）持久化存储引擎（`.data/cyclepro_db.json`），支持事务性原子替换与崩溃自愈
  - 选配：Supabase / PostgreSQL 生产级关系型数据库，配备完备的 RLS 行级安全策略 (`migrations/001_initial_schema.sql`)
- **表格渲染**：高性能虚拟滚动表格 (`VirtualizedCycleTable`)，只渲染可视区域 DOM，50,000+ 数据下保持 60 FPS 流畅操作
- **文件解析与导出**：SheetJS (XLSX, XLS) + RFC-4180 合规 CSV 解析器（支持换行、双引号转义、UTF-8 BOM 及 CSV 公式注入防护）

## 三、业务核心规则实现清单 (Rules A - G)

1. **规则 A（最新活动周期）**：根据有效活动周期数据动态计算全局最新周期（如 `2025-W23`），严格处理跨年 ISO 周历及第 52/53 周边界。
2. **规则 B（可提报判断）**：
   - SKU 在全局最新活动周期**无**提报记录 -> 符合可提报条件；
   - 从未有活动记录的 SKU 保留可提报资格；
   - 最新周期已提报的 SKU 不进入普通可提报表。
3. **规则 C（可连续提报判断）**：
   - 必须同时满足：① 最新周期存在提报；② 紧邻上一有效周期不存在提报；
   - 满足条件进入可连续提报表，并标记醒目的「⚠️ 活动价格待修改」合规预警；
   - 若最新期和上一期均有提报（连报），则不进入连续提报表。
4. **规则 D（连续状态展示）**：
   - 连续两周提报：显示「⚠️ 连报+最新已报」（红标，暂缓）；
   - 最新期提报且上一期未报：显示「⏳ 最新已报」（黄标，暂缓）；
   - 最新期无提报：显示「✅ 可提报」（绿标，建议提报）；
   - 无任何历史活动：显示「⏳ 无活动」（灰标）。
5. **规则 E（提报数据提取）**：
   - 从最新记录向前寻找，默认跳过 `remark` 非空的促销活动记录，选取最近一条无备注的常规记录；
   - 若所有历史记录均有备注，执行回退行为提取最新一条并标注「⚠️有备注」；
   - 无活动 SKU 保留并在历史字段留空。
6. **规则 F（SKU 关联规则）**：
   - 优先通过 `originalSku` 关联，回退支持 `splitSku`；
   - 缺失产品资料的活动记录正常保留展示；未提报活动的在库产品亦完整保留。
7. **规则 G（多维统计口径）**：
   - 严格区分产品 SKU 总数、有活动 SKU、无活动产品数、成功关联类目数，拒绝混淆口径。

## 四、安全与权限体系 (RBAC)

系统内置预设角色账户（密码统一为 `<角色名>123456`）：
- **超级管理员 (admin)**: `admin@cyclepro.com` / `admin123456`
  - 拥有全部权限，包括清空云端存储（双重口令二次确认 `CONFIRM_CLEAR_ALL`）、查看全局审计变更日志、导入任务监控。
- **运营主管 (manager)**: `manager@cyclepro.com` / `manager123456`
  - 拥有产品与活动数据导入、追加、替换、报表导出、备份恢复权限。
- **数据分析师 (analyst)**: `analyst@cyclepro.com` / `analyst123456`
  - 拥有全盘数据筛选检索、周期透视与三项报表 CSV 导出权限。

## 五、旧版本地数据迁移向导

针对旧版系统存储在浏览器 `localStorage` 中的键：
- `cyclepro_product_data_v3`
- `cyclepro_activity_data_v3`

新系统提供内置「旧版数据迁移」向导：
1. 点击左侧导航栏的 **旧版数据迁移**；
2. 系统自动扫描当前设备上的旧版数据并核对条数；
3. 支持一键同步校验并导入云端数据库，亦支持跨设备导入旧版 JSON 备份文件；
4. 数据完成云端持久化并返回确认后，提示迁移成功。
